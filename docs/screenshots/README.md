# FoodLink screenshots

These are authentic browser captures of the public FoodLink deployment on **November 6, 2026**. They are not generated mockups, and no application data or interface elements were changed to stage them.

| File | Page | What it shows |
| --- | --- | --- |
| `customer-home.jpg` | https://foodlink-front.onrender.com/ | Customer landing page and entry into restaurant discovery |
| `restaurant-discovery.jpg` | https://foodlink-front.onrender.com/restaurants | Search controls and the public restaurant catalog |
| `restaurant-menu.jpg` | https://foodlink-front.onrender.com/restaurants/1 | A scrolled view of menu categories, prices, and unavailable-to-order controls |

## Scope

- All three captures were taken while signed out, using public pages only.
- Restaurant discovery, search filtering, menu navigation, and English/Hebrew switching were checked in the live browser.
- The listed restaurants are reference-catalog entries, not connected ordering partners. The menu capture intentionally retains the disabled order controls.
- The management URL was checked and displayed its sign-in screen. No authenticated management screen, checkout, payment, or production order was used for these captures.
- The local emulator demonstration in the root README describes the repository's existing implementation and fixtures, not a new end-to-end test run performed for this documentation update.
- Restaurant prices and availability shown in the images are a historical snapshot. Consult the source-linked catalog for context; this project does not establish current delivery availability.

To refresh these assets, capture the same public screens after their content loads and review them for personal information before committing.
